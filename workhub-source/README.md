# WorkHub 업무 양식 프로토타입

index.html을 브라우저로 열면 실행됩니다. 별도 설치나 빌드는 필요하지 않습니다.

- index.html: 화면 구조
- styles.css: 디자인
- app.js: 양식·내역·정렬·필터
- local-files.js: 로컬 첨부파일 연결 및 열기
- dev-notes.js: 개발자용 메모 핀 (삭제하면 메모만 사라짐)

## 양식과 화면

등록 번호 외 업무 항목은 양식 설정으로 구성합니다. 새 업무 양식에는 고정 업무 항목이 없습니다. 기존 예시 데이터의 표시되지 않는 값은 보존합니다. 내역은 목록의 행마다 있는 관리 열에서 수정·삭제하고, 내역 작성·상세·수정은 대화 상자로 엽니다. 상세는 표의 데이터 값을 눌렀을 때만 열리며 셀 배경으로는 열리지 않습니다. 양식 이름·설명과 양식 항목은 양식 설정 탭의 수정 버튼으로 변경합니다. 저장하지 않은 내용이 있으면 닫거나 이동하기 전에 확인합니다.

항목은 날짜·숫자·텍스트·드롭다운·업로드를 지원합니다. 항목명·유형·필수 여부·순서와 드롭다운 선택 항목을 설정할 수 있습니다. 삭제한 항목의 값은 보존하되 표시하지 않습니다. 미리보기는 현재 열 구성과 가장 최근에 등록한 내역 한 행을 표시합니다. 새 열에 기존 값이 없으면 —로 표시합니다.

## 줄마다 입력

모든 내역은 등록 번호 하나와 한 개 이상의 줄로 저장합니다. 값은 줄에 저장하며, 줄 번호는 화면에 표시하지 않습니다. 양식 설정의 줄마다는 입력 화면만 결정합니다. 켜면 줄 추가를 제공하고, 꺼도 저장된 값은 변환하지 않아 이미 입력한 여러 줄을 그대로 표시합니다. 끈 항목의 기존 줄은 수정·삭제할 수 있지만 새 줄은 추가할 수 없습니다.

목록은 줄마다 값을 모두 표시하고 나머지 칸은 병합합니다. 정렬은 첫 줄 값을 기준으로 하며 내역은 나뉘지 않습니다. 하단 합계는 모든 줄을 더합니다. 삭제한 줄은 숨기고 변경 이력에 남깁니다.

## 등록일과 기간 필터

등록일은 내역을 저장한 시각을 시스템이 자동으로 기록하며 수정할 수 없습니다. 등록일은 별도 열 없이 등록 번호 열의 값을 눌러 모든 행의 값을 전환해 확인합니다. 열 제목은 등록 번호로 유지합니다. 기간(전체·오늘·최근 7일·이번 달·올해)과 직접 지정은 양식의 날짜 항목이 아니라 등록일을 기준으로 합니다. 직접 지정은 260404처럼 입력하거나 달력에서 고를 수 있습니다. 등록일 기능 이전에 저장되어 등록 기록이 없는 내역은 —로 표시하며 기간을 지정하면 나타나지 않습니다.

## 삭제와 이력

내역 삭제는 확인을 거친 뒤 목록에서 숨기는 방식입니다. 입력한 값은 지우지 않고 삭제 사실을 변경 이력에 남깁니다. 변경 이력은 삭제할 수 없습니다.

## 정렬과 필터

일반 열의 머리글을 누르면 오름차순·내림차순이 번갈아 적용됩니다. 숫자는 숫자 크기로 정렬하며, 값이 없는 행은 뒤에 표시합니다. 드롭다운 열은 머리글을 눌러 체크박스로 선택 항목을 필터링합니다. 같은 열의 선택 항목은 OR, 서로 다른 열의 조건은 AND로 적용합니다. 검색·여러 열 필터·한 열의 정렬을 함께 사용할 수 있습니다. 목록 하단에는 현재 조건의 건수와 숫자 항목의 합계를 표시합니다.

## 첨부파일

항목당 파일 하나를 선택하고 열 수 있습니다. 전체 절대 경로는 브라우저에서 제공하지 않습니다. 지원 브라우저에서는 읽기 전용 파일 연결 정보를 IndexedDB에 저장하며, 미지원 환경에서는 파일 사본을 같은 브라우저의 IndexedDB에 저장합니다. 서버로 전송하지 않습니다. PDF·일반 텍스트·지원 이미지는 브라우저에서 열고, 다른 형식은 다운로드로 제공합니다.

파일 연결 정보는 같은 브라우저·주소에서 사용합니다. 권한 재확인이 필요할 수 있으며, 파일 이동·삭제 또는 브라우저 데이터 삭제 후에는 다시 선택해야 합니다. 데스크톱 기본 프로그램 실행 기능은 없습니다.

## 저장 범위

양식·내역·이력은 브라우저 localStorage, 첨부파일은 IndexedDB를 사용합니다. 서버·사용자 인증·실제 권한 제어·동시 편집은 연결되지 않았습니다. 파일 URL에서의 저장 지원은 브라우저 설정에 따라 다릅니다.
